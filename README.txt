COMQUIZ — Projet de quiz HTML/CSS/JavaScript

Contenu :
- index.html : page principale
- style.css : design responsive violet
- script.js : 20 questions, minuterie, score et corrections

Tester en local :
1. Décompressez le dossier.
2. Ouvrez index.html dans un navigateur récent.
3. Une connexion Internet n'est pas nécessaire pour le fonctionnement du quiz.
   (La police distante est facultative ; une police système sera utilisée si elle n'est pas disponible.)

Publier gratuitement avec GitHub Pages :
1. Créez un compte sur https://github.com/ si nécessaire.
2. Créez un nouveau dépôt public, par exemple "comquiz".
3. Téléversez index.html, style.css et script.js à la racine du dépôt.
4. Dans Settings > Pages, choisissez Deploy from a branch, puis main et /(root).
5. GitHub affichera l'adresse publique du site après publication.

Créer le QR Code :
Le QR Code final dépend de l'adresse publique. Une fois le site publié, transmettez-moi son URL
et je pourrai générer le QR Code correspondant. Le QR Code ouvre le site via Internet.
